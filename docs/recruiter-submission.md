## Portfolio description

RetailPilot AI turns retail spreadsheets into a traceable operational workflow. Built with React, TypeScript, FastAPI and PostgreSQL, it validates Excel/CSV extracts, calculates sales and inventory KPIs, explains supplier-aware reorder quantities, governs simulated purchasing through manager approval, and exports formatted MIS reports. A read-only analyst answers six supported business questions, while four forecasting baselines use chronological backtests. The public exhibit runs on free Cloudflare Pages, Render and Neon services with isolated fictional workspaces and restricted uploads. Reproducible data, numerical tests, security regression tests and browser journeys demonstrate Excel/MIS automation, Python engineering, API integration and controlled analytical workflows. The separate authenticated ERP simulator works locally; commercial integrations and autonomous purchasing are not claimed.

Use [demo-script.md](demo-script.md) for the walkthrough and [verification.md](verification.md) for executed evidence. Do not claim measured commercial savings, organizational adoption or enterprise production readiness.
